### 设计要点

- **三轨同构**：与 PaymentManager 完全对称——`_ready()` 探测各 provider 的原生单例（`Engine.get_singleton("GodotGoogleSignIn")` / `"SignInWithApple"`），缺哪个走哪个的模拟器，互不影响。iOS 上 Google、Android 上 Apple 都自动 fallback 到模拟器
- **统一用户 Dictionary**：`{provider, user_id, display_name, email, id_token, server_token, login_time}` —— 各平台归一化后业务层不感知平台
- **流程**：平台原生认证 → id_token → NetworkClient.exchange_auth_token → server JWT → SaveManager 持久化 → emit login_succeeded
- **会话恢复**：restore_session() 从 SaveManager 启动时加载，跨启动免登录
- **Phase 2/3 接入点**：`_connect_google_signals()` / `_connect_apple_signals()` 已留桩注释，接入原生插件时只补信号连接，不动 UI 和业务层
