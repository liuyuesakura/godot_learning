# 卡牌框架验证与修复

## 概述
上一轮创建了竖屏卡牌框架（参考 db0/godot-card-game-framework），headless 验证未完成。
本轮完成全部验证，修复 4 个问题，Demo 场景 headless 运行零错误。

## 修复清单

### 1. class_name 冲突
- **问题**：`scripts/ui/components/CardView.gd`（旧，extends Panel，被 CombatScene 使用）与新框架的
  `scripts/ui/card_framework/CardView.gd`（新，extends Control）同名，Godot 全局类名唯一，导致新类全部无法解析。
- **修复**：新框架类重命名为 `BattleCard`，文件改为 `BattleCard.gd`。
  更新 FanHand/BoardGrid/CardFrameworkDemo/CardPileView 中所有 `CardView` → `BattleCard` 引用。
  旧 CardView 不动，CombatScene 不受影响。

### 2. 全局类缓存过期
- **问题**：新文件创建后 `.godot/global_script_class_cache.cfg` 未更新，FanHand/BoardGrid/CardPileView 不在缓存中。
- **修复**：删除缓存文件，用 `--headless --editor --quit` 重建。5 个新类全部注册成功。

### 3. Variant 推断错误
- **问题**：`var card := _hand.cards.back()` 在 GDScript 严格模式下报错
  （`Array[BattleCard].back()` 返回 Variant，`:=` 无法推断）。
- **修复**：改为 `var card: BattleCard = _hand.cards.back()`。

### 4. to_local() API 不存在
- **问题**：`_hand.to_local(...)` 报 "Nonexistent function" — Godot 4.7.1 的 Control 上没有此方法。
- **修复**：改用 `card.global_position = ...` 直接赋值。

## 验证结果
```
godot --headless --quit-after 30 res://scenes/card_framework_demo.tscn
→ 零错误，零警告，干净退出
```
