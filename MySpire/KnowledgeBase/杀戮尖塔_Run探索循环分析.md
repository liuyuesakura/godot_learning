# 杀戮尖塔 Run 探索循环设计分析

> 版本: 1.0 | 日期: 2026-08-05
> 关联文档: 杀戮尖塔_核心循环分析.md, 杀戮尖塔_卡牌系统分析.md

## 概述

Run 探索循环是杀戮尖塔的宏观战略层。如果卡牌系统回答"这回合怎么打"，探索循环回答"打什么、什么时候打、要不要冒风险打"。**路径选择的战略权重高于任何单张卡牌的选择**——一次错误的路径决策可以让一个成型的牌组死在 Boss 门前，而一次精妙的路径规划可以让弱牌组通过精英战获得翻盘遗物。

---

## 1. Run 结构总览

### 1.1 三幕式结构

| 维度 | Act 1 | Act 2 | Act 3 |
|------|-------|-------|-------|
| **定位** | 探索期 | 成型期 | 执行期 |
| **层数** | ~15 层 | ~15 层 | ~15 层 |
| **敌人强度** | 低 | 中 | 高 |
| **精英密度** | 低 | 中 | 高 |
| **HP 容错** | 宽容 | 收紧 | 严苛 |
| **核心任务** | 找到 build 雏形 | 核心引擎就位 | 执行 build, 微调 |
| **Boss 遗物** | 定义方向 | 强化方向 | 终极补强 |

### 1.2 难度递进弧线

三个 Act 不是简单的数值放大，而是**对玩家理解深度的递进测试**：

- **Act 1** 考验"你能不能识别哪些卡值得拿"——容错高，允许试错
- **Act 2** 考验"你能不能做出正确的放弃"——敌人变强，牌组冗余的代价放大
- **Act 3** 考验"你能不能用成型的引擎高效运转"——容错极低，每一点 HP 损耗都有战略意义

### 1.3 Act 之间的过渡

每个 Act 以 Boss 战结束。Boss 战后，玩家获得 **Boss 遗物三选一**（可跳过）。这是 run 中最重要的遗物获取节点——Boss 遗物比普通遗物更强力，通常带有显著的方向定义性（如"每回合开始多 1 能量"彻底改变出牌节奏）。

## 2. 地图生成规则

### 2.1 分支与合并

地图由程序生成，结构为**分支路径**：

- 每个 Act 约 15 层，每层有多个节点
- 路径在层间分支和合并，形成 2-4 条可选路线
- 玩家在某层选择一个节点后，只能移动到下一层中与当前路径相连的节点
- **路径一旦选择即锁定**——不能回头走另一条路

### 2.2 部分可见性

玩家只能看到**当前位置下方 1-2 层**的节点。更远的节点不可见。这是探索循环张力的核心来源：

- 你知道眼前有什么，但不知道这条路后面通向哪里
- 你可能看到一条路有精英战（高风险高回报），但不知道精英战后是篝火还是连续战斗
- 部分可见性把路径选择从"解谜"变成"风险管理"——如果有完全信息，最优路径可以算出来，张力消失

### 2.3 节点类型分布约束

地图生成遵循约束规则（非完全随机）：

| 约束 | 规则 | 设计目的 |
|------|------|---------|
| 首层无精英 | 前 1-2 层不出现精英战 | 给玩家热身空间，不在最弱时被迫打精英 |
| Boss 固定末端 | Boss 永远在最后一层 | Act 的终点和节奏锚点 |
| 篝火间距 | 篝火不过于密集 | 恢复资源保持稀缺，不能无限回血 |
| 宝箱位置 | 通常在 Act 中段 | 中段检查点奖励，给后半程提供动力 |
| 商店数量 | 每 Act 约 1-2 个 | 经济决策点保持稀缺，每次商店都是重要选择 |
| 路径必有战斗 | 每条路径至少有若干普通战 | 不存在"纯安全路线"，战斗是不可避免的 HP 消耗 |

### 2.4 路径可读性

地图设计保证玩家能**在有限信息下做有意义的推理**。你不需要看到全图就能做决策——你看到的是"这条路有精英+商店，那条路有篝火+事件"，这个局部信息已经足够制造一个真实的战略选择。

## 3. 7 种节点类型详解

每种节点类型在经济系统中承担特定的 Source/Sink 角色。理解这些角色，就理解了地图上每个节点的战略价值。

### 3.1 普通战 (Normal Combat)

| 维度 | 内容 |
|------|------|
| **Source** | 金币 [PLACEHOLDER ~10-20]、卡牌奖励（3 选 1 或跳过）、药水（概率掉落） |
| **Sink** | HP（变量，取决于敌人强度 + 玩家操作） |
| **设计目的** | 基础资源生成 + 牌组构建机会。地图的"默认节点" |
| **设计逻辑** | 普通战是 run 中最高频的节点。它的 HP 消耗可控（技术好的玩家可以无伤），但不会为零——保证 HP 资源持续有消耗压力。卡牌奖励的 3 选 1 或跳过机制与战斗系统的卡牌经济直接挂钩 |
| **设计启示** | 普通战的"技能天花板"是 HP 损耗最小化。顶级玩家和普通玩家的差距主要体现在普通战的 HP 管理上 |

### 3.2 精英战 (Elite Combat)

| 维度 | 内容 |
|------|------|
| **Source** | 遗物（必定掉落）、金币 [PLACEHOLDER ~25-35]、卡牌奖励（3 选 1 或跳过）、药水（高概率） |
| **Sink** | HP（大量，通常比普通战多 50-70%） |
| **设计目的** | 风险/回报核心阀门。遗物的主要来源（除 Boss 外） |
| **设计逻辑** | 精英战是整个探索循环中**战略权重最高的节点类型**。打精英 = 用 HP 换遗物 = 投资未来战力。不打精英 = 保留 HP 但遗物获取机会减少 = 牌组强度可能不够打后续内容。这个张力是路径选择的核心驱动力 |
| **设计启示** | 精英战的 HP 代价必须足够高，否则"必打精英"成为唯一解，路径选择失去意义。但也不能太高，否则"必避精英"成为唯一解。平衡点：精英战 HP 消耗约占最大 HP 的 20-35%，篝火回血 30% |

### 3.3 商店 (Shop)

| 维度 | 内容 |
|------|------|
| **Sink** | 金币 |
| **Source** | 购买卡牌、遗物、药水、**删牌服务** |
| **设计目的** | 经济决策中枢。金币的唯一计划性消费点 |
| **设计逻辑** | 商店是 run 中**唯一可以用金币确定性删除卡牌**的地方（事件删牌是随机的）。删牌服务定价 75 金币起跳且递增，这个数字反映了一个设计判断：**牌组精简的价值 ≥ 牌组扩展的价值**。如果删牌太便宜，所有玩家都会走极端精简流；太贵则金币失去消费意义 |
| **设计启示** | 商店的商品池是随机的（你不知道会刷出什么卡和遗物），但消费决策是确定的（你看到商品后决定买不买）。这种"随机供给 + 确定需求"的模式制造了每次商店都不同的决策 |

### 3.4 篝火 (Rest Site)

| 维度 | 内容 |
|------|------|
| **选项** | 回复 30% 最大 HP **或** 升级一张卡 |
| **设计目的** | 恢复 vs 进阶的 run 级核心二选一 |
| **设计逻辑** | 篝火是探索循环中**唯一同时充当 HP Source 和牌组进阶点的节点**。回血 = 保住当下存活；升级 = 投资未来战力。这个二选一与卡牌奖励的"拿牌 vs 跳过"形成镜像——都是在"扩展当下能力"和"保持精简/健康"之间做选择 |
| **设计启示** | 30% 回血这个数字是经过调优的：不足以从濒死恢复到安全线，但足以补偿一场普通战的消耗。如果回血太高，升级选项被边缘化；太低则篝火失去恢复功能 |

### 3.5 事件 (Event)

| 维度 | 内容 |
|------|------|
| **Source/Sink** | 完全可变（可能给遗物、卡牌、金币、HP，也可能夺走它们） |
| **设计目的** | 变数注入 + 叙事调味 + 打破路径可预测性 |
| **设计逻辑** | 事件是探索循环的"混沌因子"。没有事件，每条路径的价值可以完全用节点类型的 Source/Sink 计算。事件的不可预测性阻止了路径选择变成纯数学优化——你必须为"未知"留出缓冲 |
| **设计启示** | 事件的多选设计（通常 2-4 个选项 + 有时有隐藏条件触发选项）让每次事件都是一个小型决策谜题。好的事件选项没有 obviously correct 答案——每个选项都有代价和收益 |

### 3.6 宝箱 (Treasure)

| 维度 | 内容 |
|------|------|
| **Source** | 免费遗物（必定） |
| **Sink** | 无 |
| **设计目的** | 检查点奖励 + 节奏调节 |
| **设计逻辑** | 宝箱是无代价的纯增益节点。它的设计价值不在于"给不给东西"（必然给），而在于**它在地图上的位置影响了路径选择**。如果一条路有宝箱，这条路的价值自动提升。宝箱通常放在 Act 中段，给玩家在后半程（难度上升段）提供战力提升 |
| **设计启示** | 宝箱是"免费午餐"，在设计上需要控制数量（每 Act 通常 1 个），否则遗物通胀 |

### 3.7 Boss

| 维度 | 内容 |
|------|------|
| **Source** | Boss 遗物（3 选 1，可跳过） |
| **Sink** | HP（高风险战斗） |
| **设计目的** | Act 高潮 + build 方向定义 |
| **设计逻辑** | Boss 战是每个 Act 的终点，也是 run 中最重要的遗物获取节点。Boss 遗物比普通遗物更强力、更方向定义。3 选 1 + 可跳过的设计延续了"每个奖励是真实选择"的 Design Pillar——如果 Boss 遗物总是纯增益，它就不是一个选择，只是一个领奖动画 |
| **设计启示** | 部分 Boss 遗物是双刃剑（如"最大 HP 减少，但每回合多 1 能量"），这种设计让遗物选择本身成为一个 build-defining 决策 |

## 4. 路径决策架构

### 4.1 决策模型

路径选择是杀戮尖塔中**战略权重最高的决策类型**。一次路径决策的流程：

```
看到 1-2 层节点
  → 评估当前状态: HP / 牌组强度 / 金币 / 遗物 / 药水
  → 评估每条路径: 包含哪些节点? 风险/回报如何?
  → 选择路径 (承诺后续节点序列)
  → 逐个执行节点, 每个节点改变状态
  → 到达下一个分叉点, 重新评估
```

### 4.2 路径锁定与不可逆性

路径选择是**不可逆的**。一旦走上某条路，你无法回头选择另一条。这创造了三层压力：

1. **沉没成本压力**：已经走了 5 层，即使发现前方不利也不愿"浪费"已走的路（尽管实际上不存在浪费，因为已经获得的资源不会失去）
2. **信息不对称焦虑**：你只能看到 1-2 层，但路径可能锁定 5-8 层。你在不完全信息下做不可逆决策
3. **机会成本感知**：选择 A 路意味着放弃 B 路上的所有节点（包括可能的遗物、商店、篝火）

### 4.3 常见路径策略

| 策略 | 适用条件 | 核心逻辑 | 风险 |
|------|---------|---------|------|
| **精英路线** | HP 充裕, 牌组需要力量提升 | 用 HP 换遗物, 加速 build 成型 | HP 消耗过大, 后续无法维持 |
| **安全路线** | HP 偏低, 或牌组已成型 | 避开精英, 保留 HP 给 Boss | 遗物获取不足, 后期战力不够 |
| **商店路线** | 持有大量金币 | 路径经过商店, 消费金币买关键卡/遗物/删牌 | 商店商品随机, 可能买不到需要的 |
| **篝火路线** | HP 低 或 有卡待升级 | 路径经过多个篝火, 恢复+升级 | 战斗节点少, 资源获取总量低 |

**关键洞察**：没有"最优策略"——策略选择取决于当前状态。这正是 Design Pillar"风险随回报缩放"的实现方式。

## 5. Act 递进设计

### 5.1 Act 1: 探索期

| 维度 | 设计意图 |
|------|---------|
| **玩家体验目标** | "我的牌组可以往什么方向走?" |
| **敌人设计** | 弱, 但有少数"教训型"敌人（惩罚特定打法） |
| **卡牌奖励** | 频繁, 鼓励尝试不同卡牌组合 |
| **精英战略** | 可打可不打, HP 容错高 |
| **常见错误** | 拿太多卡 → 牌组臃肿 → Act 2 抽不到关键牌 |
| **设计目的** | 给玩家安全的实验空间, 让 build 身份从选择中涌现 |

### 5.2 Act 2: 成型期

| 维度 | 设计意图 |
|------|---------|
| **玩家体验目标** | "我的核心引擎能不能运转?" |
| **敌人设计** | 显著变强, 出现机制型敌人（逼迫特定应对） |
| **卡牌奖励** | 更谨慎——拿牌的边际收益递减, 牌组已接近成型 |
| **精英战略** | 需要决策: 牌组够强打精英? 还是保 HP? |
| **常见错误** | 不敢删卡 → 冗余牌拖累引擎 → Act 3 爆炸 |
| **设计目的** | 测试 build 的实际运转能力, 逼迫玩家做减法 |

### 5.3 Act 3: 执行期

| 维度 | 设计意图 |
|------|---------|
| **玩家体验目标** | "我能不能高效执行, 把 HP 损耗降到最低?" |
| **敌人设计** | 最强, 精英密集, 容错极低 |
| **卡牌奖励** | 边际价值最低——牌组应已完整, 多数选择跳过 |
| **精英战略** | 高风险决策: 牌组强到可以打? 还是避开保命? |
| **常见错误** | 贪心打精英 → HP 耗尽 → 死在 Boss 前 |
| **设计目的** | 考验执行力和风险管理, build 探索阶段已结束 |

## 6. 探索循环的 4 层张力来源

### 6.1 信息不对称

地图只展示 1-2 层。玩家在不完全信息下做不可逆决策。这是 roguelike 的核心张力来源——**完全信息把决策变成计算题, 零信息把决策变成赌博**。部分可见性找到了"有意义的决策"的甜区。

### 6.2 HP 作为跨节点通用货币

HP 是唯一**同时连接所有节点类型**的资源：

- 普通战消耗 HP
- 精英战大量消耗 HP
- 篝火恢复 HP
- 事件可能消耗或恢复 HP
- Boss 消耗 HP
- 商店和宝箱不与 HP 交互

这意味着 HP 是跨节点的"通用货币"——每个节点的价值都可以用"HP 收益/消耗"来衡量。**HP 经济的平衡是整个探索循环的地基**：如果 HP 太充裕，所有战斗变成无成本行为；如果太稀缺，玩家被迫走安全路线，路径选择失去意义。

### 6.3 路径锁定风险

路径不可逆创造了"每个分叉都是真实选择"的体验。如果允许走回头路，路径选择降级为"先走最近的好节点，再回头走另一个"——失去战略深度。不可逆性把"选哪条路"从简单排序升级为**不可撤销的资源承诺**。

### 6.4 Act 难度递进

三个 Act 的难度递进制造了**时间压力**。玩家不能无限探索和积累——Act 越深, 容错越小。这防止了"完美 build"的出现：你必须在资源有限的情况下做出"够好"的 build, 而不是无限优化到完美。

## 7. HP 作为跨节点通用货币

HP 在探索循环中的角色值得单独展开。它是**唯一在节点间持续存在且自然消耗的资源**：

| 节点类型 | HP 影响 | 设计意义 |
|---------|---------|---------|
| 普通战 | 消耗 (5-20) | 持续施压, 技术好的玩家可以最小化 |
| 精英战 | 大量消耗 (15-40) | HP 投资点, 用 HP 换遗物 |
| 篝火 | 恢复 30% | 唯一计划性恢复点 |
| 事件 | 可变 | 混沌因子, 可能回血也可能扣血 |
| 宝箱 | 无 | 纯增益, 不参与 HP 经济 |
| 商店 | 无 | 经济决策, 不参与 HP 经济 |
| Boss | 高消耗 | Act 终点考验, HP 管理的最终检验 |

**HP 经济的平衡公式**（概念性）：

```
Act 内 HP 净变化 = 篝火回血 + 事件回血 - 普通战消耗 - 精英战消耗 - Boss 消耗
```

如果净变化为正且过大 → 探索无压力, 路径选择失去意义
如果净变化为负且过快 → 玩家频繁死亡, 挫败感过强

平衡目标: **HP 在 Act 末段恰好处于"够打 Boss 但不敢犯错"的区间**。这需要篝火数量、敌人伤害、精英强度、Boss 难度的协同调优。

## 8. 探索循环与经济系统的交互

探索循环不是孤立的——它直接控制经济系统的**节奏和密度**：

| 经济资源 | 探索循环如何控制 | 交互效果 |
|---------|----------------|---------|
| **HP** | 篝火数量和位置决定恢复机会; 战斗节点密度决定消耗频率 | HP 经济的 Source/Sink 节奏由地图结构决定 |
| **金币** | 商店位置决定消费机会; 战斗节点数量决定获取总量 | 金币的获取(战斗)和消费(商店)在地图上空间分离, 制造囤积决策 |
| **卡牌** | 战斗节点数量决定卡牌奖励机会; 商店和事件提供删牌 | 牌组的增长和精简在地图上由不同节点驱动 |
| **遗物** | 精英战和宝箱位置决定获取机会; Boss 遗物是固定检查点 | 遗物获取节奏直接影响 build 成型速度 |
| **药水** | 战斗掉落 + 商店购买 + 事件获取 | 药水是"一次性 HP 保险", 在关键节点提供缓冲 |

**核心洞察**：探索循环是经济系统的**节奏控制器**。地图上节点的类型、数量、顺序, 直接决定了玩家在经济系统中能做多少次决策、什么时候做、以什么代价做。

## 9. 可移植设计原则

从杀戮尖塔的探索循环中, 可以提取以下可移植到其他品类的设计 DNA：

| 原则 | 杀戮尖塔的实现 | 可移植形式 |
|------|--------------|-----------|
| **部分可见 > 完全可见** | 地图只看 1-2 层 | 任何需要"规划前方路线"的系统: 技能树、关卡选择、任务链 |
| **路径不可逆 > 自由导航** | 选路后不能回头 | 任何分支选择系统: 技能专精、剧情分支、装备路线 |
| **一个持久资源作为约束** | HP 是跨节点通用货币 | 找一个在所有玩法节点中持续消耗/恢复的资源: 时间、燃料、士气、理智 |
| **节点类型有独立经济角色** | 7 种节点各有 Source/Sink | 每种玩法节点类型应对经济系统有独特的输入/输出角色 |
| **风险节点 = 力量来源** | 精英战守遗物 | 高风险玩法内容应提供其他途径得不到的核心资源 |
| **Act 结构 = 叙事弧** | 探索 → 成型 → 执行 | 任何有长度的游戏进程都应有"探索期/承诺期/执行期"的三段式弧线 |
| **恢复点 = 决策点** | 篝火回血 OR 升级 | 恢复节点不应是纯被动回血, 应提供"恢复 vs 投资"的二选一 |
| **免费奖励控制数量** | 宝箱每 Act 1 个 | 无代价资源必须严格限量, 否则通胀 |

## 附: 探索循环设计检查清单

在设计自己的 run 探索循环时, 用以下清单逐项检查:

- [ ] **路径选择是否不可逆?** 如果允许走回头路, 路径决策的战略权重归零
- [ ] **信息是否部分可见?** 完全可见 = 解谜; 零可见 = 赌博; 部分可见 = 风险管理
- [ ] **是否存在一个跨节点持久资源作为约束?** (HP、时间、燃料等)
- [ ] **每种节点类型是否有独立的经济角色?** (Source/Sink 不重叠)
- [ ] **高风险节点是否提供独特的高价值资源?** (否则没有理由冒险)
- [ ] **恢复节点是否提供"恢复 vs 投资"的二选一?** (纯被动回血浪费决策机会)
- [ ] **进程是否有三段式弧线?** (探索 → 成型 → 执行)
- [ ] **免费奖励是否限量?** (无代价资源必须控制数量, 否则通胀)
- [ ] **路径上节点序列的组合是否有战略意义?** (篝火在精英前 vs 精英后, 体验完全不同)
- [ ] **难度递进是否制造了时间压力?** (防止无限积累, 逼迫"够好就行"的决策)
- [ ] **Act 之间的过渡是否提供了方向定义性奖励?** (Boss 遗物级别的选择)
- [ ] **每个分叉点是否是真实选择?** (如果一条路明显优于另一条, 那不是选择)
