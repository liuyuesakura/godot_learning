## 1. 卡牌类型分类体系

杀戮尖塔的卡牌系统有三条正交的分类维度：**机制类型**（卡牌做什么）、**特殊属性**（卡牌怎么存在）、**稀有度**（卡牌多难获得）。任何一张卡牌都是这三个维度的交叉产物。

### 1.1 按机制类型分类

| 类型 | 玩家拥有？ | 存续时间 | 核心作用 |
|------|-----------|---------|---------|
| **Attack（攻击）** | 是 | 持续至打出或战斗结束 | 造成伤害——战斗的进攻动词 |
| **Skill（技能）** | 是 | 持续至打出或战斗结束 | 防御与工具——不造成攻击伤害的辅助行为 |
| **Power（能力）** | 是 | 打出后永久持续至战斗结束 | 被动增益——一次性投资的长期回报 |
| **Status（状态）** | 否（非玩家拥有） | 战斗中产生，战斗结束后消失 | 牌组污染——敌人的第二威胁维度 |
| **Curse（诅咒）** | 否（非玩家拥有） | run 中产生，持续至删牌或 run 结束 | 事件代价——力量换污染的交易 |

**设计要点**: Attack / Skill / Power 是玩家构建牌组的三大支柱，Status / Curse 是系统施加于玩家的负面卡牌。这个"正反两面"的结构让卡牌系统不仅是"你有什么牌"，还包括"你被迫接受了什么牌"。

### 1.2 按特殊属性分类

特殊属性是可叠加于任意机制类型之上的修饰标签，改变卡牌的存续行为。

| 属性 | 效果 | 设计作用 |
|------|------|---------|
| **Ethereal（虚空）** | 回合末若仍在手中，则消耗（Exhaust） | 制造紧迫感——"这回合不打就没了" |
| **Exhaust（消耗）** | 打出后移出本战斗 | 强力效果的一次性限制 + 牌组精简工具 |
| **Retain（保留）** | 回合结束时不弃入弃牌堆，留于手中 | 允许跨回合规划——"留到下回合用" |
| **Innate（固有）** | 每场战斗必在起手牌中 | 减少开局 RNG + 定义开局节奏 |

### 1.3 按稀有度分类

| 稀有度 | 出现概率 | 设计定位 |
|--------|---------|---------|
| **Common（普通）** | 最高 | 基础工具——可靠、低风险、构建牌组骨架 |
| **Uncommon（罕见）** | 中等 | 定向强化——引导 build 方向的关键卡 |
| **Rare（稀有）** | 最低 | build 核心——定义牌组身份的引擎卡 |

**设计要点**: 稀有度不是纯数值强弱，而是"对 build 的影响权重"。Rare 卡往往是 build 的引擎（如 Demon Form），Common 卡是支撑骨架（如 Strike、Defend）。Uncommon 卡是"方向选择器"——你选哪些 Uncommon，大致决定你的 build 走向。

## 2. 各类型设计目的与实现逻辑

### 2.1 Attack（攻击牌）

**设计目的**: Attack 是战斗的进攻动词。没有 Attack，玩家无法消灭敌人，战斗无法结束。它的存在创造了核心战术张力——**攻防权衡**。

**实现逻辑**:
- Attack 牌消耗能量，造成直接伤害
- 伤害可被敌人的 Block 减免
- 部分 Attack 带附加效果（施加状态、抽牌、连锁伤害）
- 所有角色共享基础 Attack（Strike），但各有特色 Attack

**创造的玩家决策**:
> "我有 3 能量，手里有 2 张攻击牌和 1 张防御牌。敌人下回合打 18 伤害。我要全力输出争取这回合击杀，还是要留能量防御？"

**示例卡牌**:

| 卡牌 | 费用 | 效果 | 设计模式 |
|------|------|------|---------|
| **Strike** (Ironclad·初始) | 1 | 造成 6 点伤害 | 基线攻击——定义"1 费=6 伤害"的换算基准 |
| **Bash** (Ironclad·初始) | 2 | 造成 8 点伤害，施加 2 层 Vulnerable | 多重效果——伤害 + debuff，Vulnerable 放大后续伤害 |
| **Pommel Strike** (Ironclad·普通) | 1 | 造成 9 点伤害，抽 1 张牌 | 进攻 + 过牌——不占用手牌位，自我循环 |
| **Perfected Strike** (Ironclad·普通) | 1 | 造成 6 点伤害，牌组中每有一张"Strike"牌 +2 伤害 | 条件放大——奖励 Strike 密集型牌组 |
| **Whirlwind** (Ironclad·罕见) | X | 对所有敌人造成 5 点伤害 X 次（X=消耗能量） | X 费变量——all-in 机制，奖励能量生成 |
| **Anger** (Ironclad·普通) | 0 | 造成 6 点伤害，将一张此牌的副本置入弃牌堆 | 零费杠杆 + 连锁复制——免费但堆积牌组 |
| **Searing Blow** (Ironclad·普通) | 2 | 造成 12 点伤害，可多次升级 | 投资型——消耗休息点升级但可无限成长 |

**设计分析**: Attack 牌的内部多样性来自"附加效果"而非纯伤害数值。一个 1 费 6 伤害的 Strike 和一个 1 费 9 伤害 + 抽 1 的 Pommel Strike 的差距不在于伤害（差 3 点），而在于 Pommel Strike 额外提供了过牌——它不占用手牌位，等于"免费"循环了牌组。这种设计让卡牌选择不是简单的"比大小"。

### 2.2 Skill（技能牌）

**设计目的**: Skill 是防御与工具层。它不造成攻击伤害，但提供格挡、抽牌、能量操控、状态清除等辅助功能。没有 Skill，玩家无法防御、无法过牌、无法操控手牌——战斗变成纯粹的伤害对拼。

**实现逻辑**:
- Skill 牌消耗能量，执行非伤害效果
- 主要子类：Block（格挡）、Draw（抽牌）、Energy Gain（能量生成）、Debuff（减益敌人）、Utility（特殊工具）
- Skill 是"生存层"——决定你能不能活到出牌的回合

**创造的玩家决策**:
> "我这回合抽到了强力攻击牌，但手里只有 1 张格挡牌。敌人打 20 伤害。我是输出还是活命？"

**示例卡牌**:

| 卡牌 | 费用 | 效果 | 设计模式 |
|------|------|------|---------|
| **Defend** (Ironclad·初始) | 1 | 获得 5 点格挡 | 基线防御——定义"1 费=5 格挡"的换算基准 |
| **Shrug It Off** (Ironclad·普通) | 1 | 获得 8 点格挡，抽 1 张牌 | 防御 + 过牌——比 Defend 多 3 格挡 + 过牌，是 Defend 的上位替代 |
| **Acrobatics** (Silent·普通) | 1 | 获得 3 点格挡，抽 3 张牌 | 过牌引擎——格挡是附赠，核心是抽 3 张牌的手牌刷新 |
| **True Grit** (Ironclad·普通) | 1 | 获得 7 点格挡，消耗手中一张随机牌 | 防御 + 精简——格挡比 Defend 多 2，代价是随机消耗一张牌 |
| **Battle Trance** (Ironclad·罕见) | 0 | 抽 3 张牌，下回合不能抽牌 | 零费杠杆 + 延迟代价——用未来换现在 |
| **Impervious** (Ironclad·罕见) | 2 | 获得 30 点格挡，消耗 | 一次性强力防御——panic button，Exhaust 限制滥用 |
| **Disarm** (Ironclad·罕见) | 1 | 敌人失去 2 点力量，消耗 | 一次性 debuff——对高伤害敌人是质变，Exhaust 限制叠用 |
| **Offering** (Ironclad·稀有) | 0 | 失去 6 点 HP，获得 2 点能量，抽 3 张牌 | 自我代价——HP 换 tempo，combo 引擎的核心 |

**设计分析**: Skill 牌是杀戮尖塔策略深度的主战场。Attack 决定"多快杀敌"，Skill 决定"能不能活到杀敌"。最强的 Skill 牌不是纯格挡（Impervious 的 30 格挡很强但只是一次性），而是**过牌和能量生成**——它们让你在回合内做更多事，从根本上改变能量经济。

### 2.3 Power（能力牌）

**设计目的**: Power 是投资层。打出一张 Power 消耗能量但永久持续至战斗结束，创造一个持续的被动效果。它的核心设计张力是**tempo loss 换 scaling**——你这回合花 3 能量打 Demon Form（什么都没做），但接下来每回合都 +2 力量。

**实现逻辑**:
- Power 牌打出后，效果持续至战斗结束
- 效果在每回合特定时机触发（通常在回合末）
- Power 是"build 引擎"——你的 Power 组合定义了你的战斗风格
- Power 牌通常较贵（2-3 能量），反映其持续价值

**创造的玩家决策**:
> "我有 3 能量，手里有 Demon Form（3 费，每回合 +2 力量）和两张攻击牌。这回合打 Demon Form 等于空过一回合，但如果不打，后面几回合的伤害不够。我赌不赌？"

**示例卡牌**:

| 卡牌 | 费用 | 效果 | 设计模式 |
|------|------|------|---------|
| **Demon Form** (Ironclad·稀有) | 3 | 每回合结束获得 2 点力量 | 线性缩放引擎——力量复合增长，长战斗的质变卡 |
| **Metallicize** (Ironclad·罕见) | 1 | 每回合结束获得 3 点格挡 | 被动防御——不花能量就能回防，对多目标战斗很强 |
| **Inflame** (Ironclad·罕见) | 1 | 获得 3 点力量 | 即时增益——一次投入永久受益，比 Demon Form 便宜但不成长 |
| **Feel No Pain** (Ironclad·罕见) | 1 | 每当一张牌被消耗时，获得 3 点格挡 | 连锁触发——配合 Exhaust 牌形成防御引擎 |
| **Combust** (Ironclad·罕见) | 1 | 每回合结束失去 1 HP，对所有敌人造成 5 点伤害 | 自我代价 + 被动输出——AOE 场景的稳定伤害源 |
| **Barricade** (Ironclad·稀有) | 3 | 格挡不在回合开始时消失 | build 定义卡——彻底改变防御逻辑，格挡可累积 |
| **Rupture** (Ironclad·罕见) | 1 | 每当因卡牌效果失去 HP 时，获得 1 点力量 | 连锁触发——配合自伤卡形成力量成长引擎 |
| **Footwork** (Silent·罕见) | 1 | 获得 1 点敏捷（每回合 +1 格挡） | 缩放防御——Dexterity 是 Silent 的核心防御属性 |

**设计分析**: Power 牌是 build 身份涌现的主要载体。玩家不需要在开局"选择 build"——而是通过在 run 中遇到并选择哪些 Power 牌，自然形成"力量流"（Demon Form + Inflame）、"防御流"（Metallicize + Footwork + Barricade）、"消耗流"（Feel No Pain + Exhaust 牌）等构建方向。这正是核心循环分析中"构建身份涌现"支柱的实现机制。

### 2.4 Status（状态牌）

**设计目的**: Status 是**第二威胁维度**。敌人不只攻击你的 HP——它们攻击你的牌组。Status 牌在战斗中被混入玩家的抽牌堆，污染手牌质量，稀释关键牌的抽到概率。

**实现逻辑**:
- Status 牌不是玩家主动加入牌组的，而是敌人攻击或环境效果产生
- 战斗结束后，Status 牌消失（不进入 run 级别的牌组）
- Status 牌通常不可打出（unplayable），占据手牌位但不提供任何功能
- 部分 Status 牌有负面效果（如 Burn：回合末对自己造成伤害）

**创造的玩家决策**:
> "敌人往我牌组塞了 3 张 Wound，现在我的牌组有 15 张牌其中 3 张是废牌。我需不需要调整战术？要不要带一张能消耗牌的 Skill 来清理？"

**示例卡牌**:

| 卡牌 | 费用 | 效果 | 设计作用 |
|------|------|------|---------|
| **Wound** | 不可打出 | 无效果 | 纯污染——占据手牌位，什么都不做 |
| **Burn** | 不可打出 | 回合结束对自己造成 2 点伤害 | 主动污染——占位 + 持续伤害，双重威胁 |
| **Dazed** | 不可打出 | 虚空（回合末消耗） | 临时污染——比 Wound 轻，下回合消失 |
| **Void** | 不可打出 | 抽到时失去 1 点能量 | 能量窃取——最危险的 Status，直接打击能量经济 |
| **Slimed** | 1 | 消耗 | 可清除——花 1 能量清理，是"可处理的污染" |

**设计分析**: Status 系统的精妙之处在于它让"牌组健康度"成为独立的生存维度。玩家不仅要管理 HP 和能量，还要管理牌组的质量。这创造了对 Exhaust 牌（如 True Grit、Second Wind）的独立需求——它们不只是"消耗自己的牌"，而是"清理牌组污染"的工具。如果没有 Status，Exhaust 类 Skill 的价值会大幅下降。

### 2.5 Curse（诅咒牌）

**设计目的**: Curse 是 run 级别的牌组污染，通常作为事件的代价出现。它的设计目的是创造**跨战斗的经济决策**——你要不要接受一个长期负担来换取即时力量？

**实现逻辑**:
- Curse 牌在 run 中通过事件、某些遗物效果混入玩家牌组
- Curse 持续至被删牌服务移除或 run 结束
- Curse 牌通常不可打出，但部分有被动负面效果
- Curse 是"投资"的反面——你不是获得力量，而是接受负担以换取其他收益

**创造的玩家决策**:
> "事件给我选择：拿一个遗物但获得一张 Curse，或跳过。我的牌组有 20 张牌，加一张 Curse 意味着关键牌抽到概率下降约 5%。这个遗物值不值？"

**示例卡牌**:

| 卡牌 | 费用 | 效果 | 产生场景 |
|------|------|------|---------|
| **Ascender's Bane** | 不可打出 | 无效果 | 事件"Neow"的代价选项之一 |
| **Decay** | 不可打出 | 抽到时对自己造成 2 点伤害 | 事件代价——惩罚每场战斗的抽牌 |
| **Shame** | 不可打出 | 抽到时获得 1 层 Frail（格挡减半） | 事件代价——惩罚防御策略 |
| **Doubt** | 不可打出 | 抽到时对自己施加 1 层 Weak | 事件代价——惩罚攻击策略 |
| **Normality** | 不可打出 | 手中有此牌时，每回合最多打 3 张牌 | 事件代价——限制出牌节奏 |
| **Injury** | 不可打出 | 无效果 | 事件代价——纯牌组膨胀 |

**设计分析**: Curse 和 Status 的区别在于"存续时间"——Status 是战斗级别的，Curse 是 run 级别的。这个时间差让 Curse 的代价更重，也更有策略意义。删牌服务（75 金币起）的定价逻辑部分基于此——移除一张 Curse 不只是清理一张废牌，而是恢复整个 run 的牌组健康度。

## 3. 特殊属性的设计意图

### 3.1 Ethereal（虚空）

| 属性 | 效果 | 设计目的 |
|------|------|---------|
| Ethereal | 回合末若仍在手中，则消耗 | 制造"不用就没了"的紧迫感 |

**设计逻辑**: Ethereal 卡牌通常效果较强（如 Ghostly Armor：获得 10 格挡，0 费），但如果你这回合没打它，它就消失了。这迫使玩家在"最优时机"和"现在用掉"之间做权衡。

**创造的手牌管理张力**: 没有 Ethereal 时，玩家可以放心弃牌——不用的牌下回合还能从弃牌堆抽回来。有了 Ethereal，"不打出"本身成为一种代价。这让手牌管理从"选哪些打"升级为"哪些留、哪些必须这回合打"。

**示例**:
- **Ghostly Armor** (Ironclad·普通): 0 费，获得 10 格挡，虚空——免费 10 格挡很强，但你必须这回合用掉
- **FTL** (Silent·普通): 0 费，造成 1 点伤害，抽 1 张牌，若本回合打出的第一张牌则虚空——零费过牌，但时机受限

### 3.2 Exhaust（消耗）

| 属性 | 效果 | 设计目的 |
|------|------|---------|
| Exhaust | 打出后移出本战斗 | 限制强力效果 + 提供牌组精简工具 |

**设计逻辑**: Exhaust 有两个截然不同的设计用途：
1. **限制强力效果**: 一张卡太强了，不能让玩家每回合都打（如 Impervious 30 格挡、Disarm 减 2 力量）。Exhaust 让它只能用一次，平衡了效果强度。
2. **牌组精简工具**: 部分 Exhaust 卡的效果是"消耗其他牌"（如 True Grit、Second Wind），让玩家在战斗中清理 Status 和低价值卡，改善后续抽牌质量。

**创造的战略价值**: Exhaust 卡在长战斗（Boss、精英）中价值最高——因为长战斗中牌组会被循环多次，精简一张牌的累积收益更大。在短战斗中，Exhaust 的"牌组精简"价值不大，但"一次性强力效果"仍有用。

**示例**:
- **Impervious** (Ironclad·罕见): 2 费，获得 30 格挡，消耗——panic button，一次性挡住大量伤害
- **Second Wind** (Ironclad·普通): 1 费，消耗手中所有非攻击牌，每消耗一张获得 5 格挡——清理废牌 + 获得格挡的 combo
- **True Grit** (Ironclad·普通): 1 费，获得 7 格挡，消耗手中一张随机牌——格挡 + 随机精简

### 3.3 Retain（保留）

| 属性 | 效果 | 设计目的 |
|------|------|---------|
| Retain | 回合结束时不弃入弃牌堆，留于手中 | 允许跨回合规划 |

**设计逻辑**: 正常情况下，回合结束时手牌全部弃入弃牌堆。Retain 打破了这个规则——你可以把一张牌"存"到下回合用。这让玩家可以执行跨回合的战术规划。

**创造的规划深度**: 没有 Retain 时，每回合是独立的——你只能基于这回合的手牌做决策。有了 Retain，你可以"准备"——这回合留一张高伤害牌，下回合配合抽到的 Vulnerable 一起打。这让战斗有了"回合间战略"的层次。

**风险**: Retain 的手牌占用手牌位（基础手牌上限 10），如果保留太多牌，下回合抽牌时会溢出，反而损失。这创造了"留多少"的微调决策。

**示例**:
- **Well-Laid Plans** (Silent·罕见): 1 费，Power，每回合可保留 1 张牌——将 Retain 变为持续能力
- **Glass Knife** (Silent·稀有): 1 费，造成 8 点伤害两次，每次永久减少 2 伤害，保留——强力但衰减，Retain 让你可以选择时机

### 3.4 Innate（固有）

| 属性 | 效果 | 设计目的 |
|------|------|---------|
| Innate | 每场战斗必在起手牌中 | 减少开局 RNG + 定义开局节奏 |

**设计逻辑**: 正常情况下，起手 5 张牌是从牌组随机抽取的。Innate 打破了这个规则——标记为 Innate 的牌必定出现在起手。这让玩家可以"设计"开局——比如保证起手有防御牌、或者保证起手有某张关键 combo 牌。

**创造的开局策略**: 没有 Innate 时，玩家对开局没有控制——可能起手 5 张攻击牌面对一个打 20 伤害的敌人，也可能起手 5 张防御牌完全无法输出。Innate 让玩家可以"锚定"开局，减少极端 RNG 的惩罚。

**风险**: 如果牌组中 Innate 牌太多，起手牌会被它们占满，反而减少了"随机抽到好牌"的机会。Innate 牌的数量自然受手牌上限限制。

**示例**:
- **Survivor** (Silent·初始): 1 费，获得 8 格挡，弃 1 张牌，固有——保证 Silent 起手有防御选项
- **Neutalize** (Silent·初始): 0 费，造成 3 伤害，施加 1 Weak，固有——保证 Silent 起手有零费可用

## 4. 卡牌设计模式

以下七种设计模式是杀戮尖塔卡牌设计的"语法规则"。理解这些模式，就能解构游戏中的几乎每一张卡，也能为新卡牌设计提供框架。

### 4.1 条件放大（Conditional Amplification）

**模式定义**: 卡牌在满足特定条件时效果增强。

**设计目的**: 创造牌组构建的方向性——你为了满足条件而去构建牌组，而不是随机堆叠。

| 示例卡牌 | 条件 | 基础效果 | 条件满足效果 |
|---------|------|---------|------------|
| **Perfected Strike** | 牌组中有"Strike"牌 | 6 伤害 | +2 伤害/张 Strike |
| **Heavy Blade** | 力量属性 | 14 伤害 | 力量 × 3 计入伤害（通常 ×1） |
| **Dropkick** | 目标有 Vulnerable | 5 伤害 | 额外获得 1 能量 + 抽 1 牌 |
| **Reckless Charge** | 无（但有副作用） | 7 伤害 | 将一张 Dazed 置入弃牌堆 |

**实现逻辑**: 条件卡的基础效果通常低于平均（如 Dropkick 5 伤害/1 费，低于 Strike 的 6 伤害），但条件满足后远超平均。这迫使玩家在"拿不拿这张条件卡"时思考"我的牌组能不能满足条件"。

### 4.2 多重效果（Multi-Effect）

**模式定义**: 一张卡同时执行两个或更多功能。

**设计目的**: 创造卡牌弹性——一张多重效果卡在任何情况下都不会完全没用。

| 示例卡牌 | 效果 1 | 效果 2 | 设计价值 |
|---------|--------|--------|---------|
| **Bash** | 8 伤害 | 施加 2 Vulnerable | 攻击 + debuff，Vulnerable 放大全队伤害 |
| **Shrug It Off** | 8 格挡 | 抽 1 牌 | 防御 + 过牌，不占手牌位 |
| **Pommel Strike** | 9 伤害 | 抽 1 牌 | 攻击 + 过牌，自我循环 |
| **Acrobatics** | 3 格挡 | 抽 3 牌 | 轻防御 + 重过牌，以格挡为附赠 |

**实现逻辑**: 多重效果卡的总价值高于单效果卡，但单效果数值低于专用卡（如 Shrug It Off 的 8 格挡 < Defend 的 5 格挡 + 某张过牌卡的格挡）。这种设计让"多功能"和"专精"形成选择张力。

### 4.3 缩放引擎（Scaling Engine）

**模式定义**: 卡牌的效果随时间或使用次数增长。

**设计目的**: 创造"投资决策"——现在花能量/回合换未来收益，让长战斗（Boss、精英）变得可赢。

| 示例卡牌 | 缩放方式 | 投入 | 回报 |
|---------|---------|------|------|
| **Demon Form** | 每回合 +2 力量 | 3 能量 + 一回合空过 | 力量指数级复合增长 |
| **Inflame** | 即时 +3 力量（永久） | 1 能量 | 永久 +3 伤害/攻击 |
| **Limit Break** | 力量翻倍 | 1 能量 | 力量 ×2，配合 Demon Form 爆发 |
| **Footwork** | 每回合 +1 敏捷 | 1 能量 | 每回合 +1 格挡，永久累积 |
| **Metallicize** | 每回合 +3 格挡 | 1 能量 | 被动防御，不需主动操作 |

**实现逻辑**: 缩放卡的价值与战斗长度正相关。在 3 回合的普通战斗中，Demon Form 的价值有限（3 回合 × 2 力量 = 6 力量，但第一回合什么都没做）。在 10 回合的 Boss 战中，Demon Form 是质变（10 × 2 = 20 力量）。这让缩放卡自然成为 Boss 战的核心策略。

### 4.4 连锁触发（Combo Trigger）

**模式定义**: 卡牌的效果在其他事件发生时触发，形成连锁反应。

**设计目的**: 创造牌组内部的协同效应——卡牌之间互相加成，形成大于部分之和的 build。

| 示例卡牌 | 触发条件 | 触发效果 | 连锁对象 |
|---------|---------|---------|---------|
| **Feel No Pain** | 一张牌被消耗 | 获得 3 格挡 | 所有 Exhaust 牌 |
| **Rupture** | 因卡牌失去 HP | 获得 1 力量 | 所有自伤牌（Offering、Bloodletting、Combust） |
| **Chemical X** (遗物) | 打出 X 费牌 | 额外 +2 效果 | 所有 X 费牌（Whirlwind、Malaise） |
| **Tantrum** + **Rupture** | 自伤触发力量 | 力量增强伤害 | 伤害又触发更多自伤... |

**实现逻辑**: 连锁触发是 build 身份涌现的"胶水"。单独的 Feel No Pain 只是一张防御 Power，单独的 True Grit 只是一张消耗 Skill。但 Feel No Pain + True Grit + Second Wind + Impervious 组合在一起，就形成了"消耗流"——每次消耗都获得格挡，防御体系自给自足。连锁触发让玩家在 run 中自然发现这些组合，而不是在开局就预设。

### 4.5 自我代价（Self-Cost）

**模式定义**: 卡牌的效果以消耗玩家自身资源（HP、能量、手牌）为代价。

**设计目的**: 将 HP 从"纯生存条"转化为"可消费资源"，扩展决策空间。

| 示例卡牌 | 代价 | 效果 | 设计价值 |
|---------|------|------|---------|
| **Offering** | 失去 6 HP | 获得 2 能量 + 抽 3 牌 | HP 换 tempo——combo 引擎的核心 |
| **Bloodletting** | 失去 3 HP | 获得 2 能量 | HP 换能量——更便宜的 Offering |
| **Combust** | 每回合 -1 HP | 对所有敌人 5 伤害 | HP 换被动输出——长战斗的稳定 AOE |
| **Reckless Charge** | 塞一张 Dazed | 7 伤害 | 牌组污染换即时伤害 |
| **True Grit** | 消耗随机 1 牌 | 7 格挡 | 手牌资源换防御 |

**实现逻辑**: 自我代价卡让 HP 不再是"降到 0 就死"的简单阈值，而是"每点 HP 值多少 tempo"的连续决策。一个满血玩家面对弱敌人时，用 Offering 换 tempo 是划算的；一个残血玩家面对 Boss 时，每一滴 HP 都是命。这种"HP 价值随情境变化"的设计让战斗决策有了动态深度。

### 4.6 零费杠杆（Zero-Cost Lever）

**模式定义**: 0 费卡牌，不消耗能量但提供效果。

**设计目的**: 填充能量预算的"间隙"，让回合内动作密度更高。

| 示例卡牌 | 费用 | 效果 | 限制/代价 |
|---------|------|------|---------|
| **Anger** | 0 | 6 伤害 | 将副本置入弃牌堆（牌组膨胀） |
| **Finesse** | 0 | 2 格挡 + 抽 1 牌 | 效果较弱 |
| **Dropkick** | 0 | 5 伤害 | 仅当目标有 Vulnerable 时退费 + 抽 1 |
| **Battle Trance** | 0 | 抽 3 牌 | 下回合不能抽牌 |
| **Flex** | 0 | 获得 2 力量 | 回合末失去 2 力量 |

**实现逻辑**: 0 费卡的核心价值不在于单卡强度，而在于"不占能量预算"。在 3 能量的回合里，打一张 3 费牌和打一张 3 费 + 两张 0 费牌的差距巨大。0 费卡让"能量效率"成为牌组构建的隐性维度——一个有很多 0 费卡的牌组，每回合能做的事比纯 1-2 费牌组多得多。

### 4.7 X 费变量（Variable Cost）

**模式定义**: 卡牌标注为 X 费，打出时消耗所有可用能量，效果按消耗能量计算。

**设计目的**: 创造"all-in"决策——押上全部能量换取最大效果。

| 示例卡牌 | 费用 | 效果 | 设计价值 |
|---------|------|------|---------|
| **Whirlwind** | X | 对所有敌人造成 5 伤害 × X 次 | AOE all-in——多目标场景的清场技 |
| **Malaise** | X | 对敌人施加 X 层 Weak，消耗 | Debuff all-in——高费时完全封锁敌人攻击 |
| **Skewer** | X | 造成 6 伤害 × X 次（Silent） | 单目标 all-in——配合能量生成的爆发技 |
| **Whirlwind Strike** | X | 类似 Whirlwind（Watcher） | 跨角色的 X 费模板 |

**实现逻辑**: X 费卡创造了一种独特的决策——"我这回合要不要把所有能量都给这张牌"。配合能量生成卡（如 Offering、Bloodletting、Adrenaline），X 费卡可以打出远超 3 能量的效果。这使得"能量生成"成为独立的 build 方向——不为了多打几张牌，而是为了喂大一张 X 费卡。

## 5. 升级系统设计

### 5.1 机制概述

- 每张卡牌可在**篝火**（Rest Site）升级一次（Searing Blow 除外，可多次升级）
- 升级是 run 内永久效果，持续至 run 结束
- 升级效果通常为：伤害/格挡 +2~+3、附加效果层数 +1、费用 -1、或机制质变

### 5.2 升级的三大设计模式

| 模式 | 说明 | 示例 |
|------|------|------|
| **数值增量** | 伤害/格挡/层数增加 | Strike 6→9 伤害；Defend 5→8 格挡 |
| **费用降低** | 能量消耗 -1 | Bash 2→1 费；Shrug It Off 1→0 费 |
| **机制质变** | 效果本身改变 | Searing Blow 可重复升级；Demon Form +2→+3 力量/回合 |

### 5.3 篝火决策的设计张力

篝火提供两个选项（基础）：**休息回血 30%** 或 **升级一张牌**。这个二选一是 run 级别的核心决策：

- **升级**: 牌组永久变强，但如果当前 HP 低，可能在下一场战斗死亡
- **回血**: 更安全，但牌组没有成长，长期竞争力不变

**设计分析**: 这个决策的精妙之处在于它把"短期安全"和"长期投资"放在同一个天平上。如果篝火只能升级，游戏会过于鼓励冒险（低血也升级）；如果篝火只能回血，牌组成长缺少一个有代价的入口。二选一让每次篝火都是真实的策略决策。

## 6. 卡牌与核心循环的交互

### 6.1 卡牌在 Moment-to-Moment 层的作用

卡牌是回合内决策的**唯一载体**。每回合的决策可以拆解为：

```
能量预算（3） → 评估手牌 → 读敌人意图 → 选择出牌序列 → 结算
     ↑                                                    ↓
     ←←←←←←←←←← 资源变化反馈 ←←←←←←←←←←←←←←←←←←←←←←←←
```

卡牌的**费用**决定了能量如何分配；卡牌的**效果**决定了回合的产出；卡牌的**特殊属性**（Ethereal/Retain）决定了手牌管理的策略。这一层的决策密度直接由卡牌设计的多样性决定——如果所有卡牌都是"X 费造成 Y 伤害"，回合决策就退化为比大小。

### 6.2 卡牌在 Session 层的作用

卡牌在 session 层是**奖励系统的核心载体**。每次战斗胜利后的卡牌选择是 run 内最重要的经济决策：

```
战斗胜利 → 3 选 1 卡牌奖励 → 拿 or 跳过 → 牌组结构变化 → 影响后续战斗策略
```

卡牌的**稀有度**系统控制了奖励的质量分布；**卡牌可跳过**机制让"不拿"成为策略选择；**卡牌之间的连锁触发**让后续选择受先前选择影响——这种"路径依赖"是 session 层策略深度的来源。

### 6.3 卡牌在 Long-Term 层的作用

卡牌在 long-term 层是**解锁系统的核心内容**：

```
Run 结束 → 新卡牌加入随机池 → 后续 run 的构建空间扩大 → 新 build 成为可能
```

解锁系统让卡牌池从"最小可玩集"逐步扩展到"完整集"。这个过程的设计目的是让新玩家不会被卡牌数量淹没——前几次 run 只看到基础卡牌，学会核心机制后再逐步接触更复杂的卡牌。

### 6.4 系统交互矩阵

| 系统对 | 交互关系 | 说明 |
|--------|---------|------|
| 卡牌 × 能量系统 | **intended** | 能量限制卡牌出牌数量，创造取舍 |
| 卡牌 × 敌人意图 | **intended** | 意图决定卡牌选择优先级（攻 vs 防） |
| 卡牌 × 路径系统 | **intended** | 路径决定哪些战斗/商店/篝火可达，影响卡牌获取和升级 |
| 卡牌 × 遗物系统 | **intended** | 遗物修改卡牌效果（如 Chemical X 增强 X 费牌） |
| 卡牌 × Status/Curse | **acceptable** | 污染牌组稀释卡牌质量，创造牌组管理需求 |
| Exhaust × Feel No Pain | **intended** | 消耗触发格挡，形成 combo |
| 自伤卡 × Rupture | **intended** | 自伤触发力量，形成 combo |
| 零费卡 × 能量生成 | **intended** | 能量生成让零费卡的价值上升（更多回合内动作） |
| Searing Blow × 升级系统 | **intended** | 可重复升级创造投入型 build |
| Innate × 手牌上限 | **acceptable** | Innate 牌太多会占满起手，自然限制数量 |

## 7. 设计启示与可移植要点

### 7.1 卡牌系统的核心设计原则

| 原则 | 说明 | 可移植性 |
|------|------|---------|
| **每张卡创造一个决策** | 卡牌不是"数值容器"，而是"决策入口"——每张卡应该让玩家面临一个选择 | 适用于任何有"选项"的系统 |
| **效果多样性 > 数值多样性** | 10 张伤害 5~15 的卡不如 10 张各有独特效果的卡 | 适用于任何 RPG/策略游戏 |
| **条件创造方向** | 条件卡引导玩家构建牌组方向，比直接给"强力卡"更有策略深度 | 适用于任何 build 系统 |
| **代价是资源的另一种用法** | 自伤/消耗/弃牌不是"惩罚"，而是让 HP/手牌成为可消费资源 | 适用于任何有资源管理的游戏 |
| **反面也是设计** | Status/Curse 不是"垃圾"，是让玩家管理"负面"的独立维度 | 适用于任何经济系统 |

### 7.2 如果你在设计自己的卡牌游戏

**先回答这些问题**:

1. **你的核心动词是什么？**（杀戮尖塔是"出牌"，你的游戏是什么？）
2. **你的能量约束是什么？**（杀戮尖塔是 3 能量/回合，你的约束机制是什么？）
3. **你的"信息透明度"在哪里？**（杀戮尖塔明牌敌人意图，你的游戏明牌什么、隐藏什么？）
4. **你的"积累可选"机制是什么？**（杀戮尖塔可以跳过卡牌奖励，你的游戏允许拒绝奖励吗？）
5. **你的卡牌之间有没有连锁触发？**（如果没有，卡牌选择就是独立的，缺乏路径依赖）

**卡牌设计检查清单**:

- [ ] 每张卡牌是否有明确的设计目的（不是"多一张牌"）？
- [ ] 每张卡牌是否创造了至少一个玩家决策？
- [ ] 卡牌之间是否存在连锁触发的可能（combo 空间）？
- [ ] 是否有"反面卡牌"（Status/Curse 或类似机制）作为独立威胁维度？
- [ ] 条件卡的"条件"是否可被牌组构建满足？
- [ ] 0 费/低费卡是否有足够的限制以防止滥用？
- [ ] 升级/强化系统是否创造了"短期安全 vs 长期投资"的决策？
