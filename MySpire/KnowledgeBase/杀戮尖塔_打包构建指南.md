## 1. 前置环境准备

### 1.1 通用（所有平台）

| 依赖 | 说明 | 下载 |
|------|------|------|
| **Godot 4.3+** | 标准版即可（无需 .NET 版），需配置 CLI | https://godotengine.org/download |
| **导出模板** | Godot 编辑器 → 编辑器 → 管理导出模板 → 下载 | 编辑器内操作 |

设置 Godot CLI 环境变量（Windows）：

```batch
REM 方案 A: 加入系统 PATH（推荐）
REM 将 godot.exe 所在目录加入 PATH

REM 方案 B: 设置环境变量
set GODOT_PATH=C:\path\to\godot.exe
```

macOS：

```bash
export GODOT_PATH=/Applications/Godot.app/Contents/MacOS/Godot
# 或
brew install godot
```

### 1.2 Android 额外依赖

| 依赖 | 版本 | 说明 |
|------|------|------|
| **JDK** | 17+ | keytool 签名需要，Adoptium Temurin 即可 |
| **Android SDK** | API 34 | 通过 Android Studio SDK Manager 安装 |
| **Android NDK** | r23c | Godot 导出模板需要（通常自动下载） |
| **GodotGooglePlayBilling 插件** | Godot 4 版本 | 放入 `android/plugins/`（见该目录 README） |

安装 Android Studio 后，通过 SDK Manager 安装：
- Android SDK Platform 34
- Android SDK Build-Tools 34
- Android SDK Command-line Tools
- NDK (Side by side)

### 1.3 iOS 额外依赖

| 依赖 | 说明 |
|------|------|
| **macOS** | iOS 构建只能在 macOS 上进行（Apple 限制） |
| **Xcode 15+** | 从 App Store 安装 |
| **Apple Developer 账号** | $99/年，用于签名和 App Store 上传 |
| **签名证书 + Provisioning Profile** | 在 developer.apple.com 或 Xcode 中创建 |

> **注意**：Godot 导出 Xcode 工程可以在任何平台进行，但编译 IPA 必须 macOS + Xcode。

## 2. 导出预设说明

导出配置文件：`Client/export_presets.cfg`

| 预设 | 平台 | 格式 | 用途 |
|------|------|------|------|
| `Android Debug (APK)` | Android | .apk | 开发测试、真机调试 |
| `Android Release (AAB)` | Android | .aab | Google Play 上架 |
| `iOS (Xcode Project)` | iOS | .xcodeproj | Xcode 工程导出 |

### 关键配置项

```ini
# Android
package/unique_name = "com.myspire.game"     # 包名
package/version_code = 1                       # 版本号（整数递增）
package/version_name = "1.0.0"                 # 版本名（显示给用户）
gradle_build/min_sdk = 24                      # 最低 Android 7.0
gradle_build/target_sdk = 34                   # 目标 Android 14
plugins/GodotGooglePlayBilling = true          # 启用 Google Play Billing

# iOS
application/bundle_identifier = "com.myspire.game"  # Bundle ID
application/short_version = "1.0.0"                   # App Store 版本号
application/version = "1"                             # Build 号
min_ios_version = 14.0                                # 最低 iOS 14
capabilities/in_app_purchases = true                  # 启用 IAP
orientations/portrait = true                           # 仅竖屏
```

### 修改导出预设

两种方式：

1. **Godot 编辑器**（推荐）：项目 → 导出 → 选择预设 → 编辑
2. **直接编辑文件**：修改 `export_presets.cfg`，注意 INI 格式

## 3. Android 打包流程

### 3.1 Debug APK（快速测试）

```
build\build_android.bat debug
```

输出：`build/dist/MySpire-debug.apk`

特点：
- 使用 Godot 内置 debug 签名，无需 keystore
- 脚本压缩（GDScript 字节码），可安装到真机
- 适合日常开发验证

### 3.2 Release AAB（上架 Google Play）

**步骤 1：生成签名 Keystore（仅首次）**

```batch
build\generate_keystore.bat
```

按提示输入密码。生成的文件：
```
build/keystore/myspire_release.keystore  ← 绝对不能提交到 Git！
```

**步骤 2：配置密码**

编辑 `export_presets.cfg`，在 `[preset.1.options]` 下填写：

```ini
keystore/release="res://build/keystore/myspire_release.keystore"
keystore/release_user="myspire"
keystore/release_password="你的密码"
```

**步骤 3：导出 AAB**

```batch
build\build_android.bat release
```

输出：`build/dist/MySpire-release.aab`

**步骤 4：上传 Google Play**

1. 登录 [Google Play Console](https://play.google.com/console)
2. 选择应用 → 生产版本 → 创建新版本
3. 上传 `MySpire-release.aab`
4. 填写版本说明 → 审核 → 发布

### 3.3 版本号递增

每次发布新版本，修改 `export_presets.cfg`：

```ini
# preset.1.options
package/version_code=2        # ← 每次发布 +1
package/version_name="1.0.1"  # ← 语义化版本
```

## 4. iOS 打包流程

### 4.1 导出 Xcode 工程（可在 Windows 执行）

```batch
build\build_all.bat ios
```

输出：`build/ios/MySpire.xcodeproj`

> 此步骤仅生成 Xcode 工程文件，不编译 IPA。

### 4.2 在 macOS 上编译 IPA

将项目传到 macOS，然后：

```bash
# 方式 A: 使用构建脚本
cd Client
chmod +x build/build_ios.sh
./build_ios.sh ipa          # Development IPA（设备测试）

# 方式 B: 手动使用 Xcode
open build/ios/MySpire.xcodeproj
# 在 Xcode 中：
#   1. 选择签名 Team
#   2. Product > Archive
#   3. Organizer > Distribute App
```

### 4.3 上架 App Store

```bash
# 方式 A: Xcode Archive + 上传
./build_ios.sh archive
# 然后在 Xcode > Organizer 中上传

# 方式 B: 命令行 altool 上传
xcrun altool --upload-app \
    -f build/dist/MySpire.ipa \
    -t ios \
    -u "apple@email.com" \
    -p "app-specific-password"
```

### 4.4 iOS 签名配置

1. 在 [developer.apple.com](https://developer.apple.com) 创建：
   - App ID（Bundle ID: `com.myspire.game`）
   - Development 证书（开发测试）
   - Distribution 证书（App Store 上架）
   - Provisioning Profile（关联 App ID + 证书 + 设备）

2. 在 Xcode 中配置：
   - 打开 `MySpire.xcodeproj`
   - 选择 MySpire target → Signing & Capabilities
   - 勾选 Automatically manage signing
   - 选择 Team

### 4.5 App Store Connect 配置

1. 创建 App，Bundle ID 选择 `com.myspire.game`
2. 内购商品：
   - 创建与 `iap_products.json` 中 `apple_id` 一致的商品
   - 设置价格、描述、截图
   - 签署 Paid Applications Agreement
3. 提交审核：
   - 截图（竖屏 6.7"/6.5"/5.5"）
   - 描述文本
   - 隐私政策 URL

## 5. 一键构建命令

### 5.1 全平台构建（Windows）

```batch
REM 构建所有（Android APK + AAB + iOS Xcode 工程）
build\build_all.bat all
```

### 5.2 单平台构建

```batch
REM Android only (APK + AAB)
build\build_android.bat all

REM Android Debug APK only
build\build_android.bat debug

REM Android Release AAB only
build\build_android.bat release

REM iOS Xcode 工程导出
build\build_all.bat ios
```

### 5.3 macOS 上构建 iOS

```bash
chmod +x build/build_ios.sh

# 仅导出 Xcode 工程
./build_ios.sh export

# 导出 + 编译 Development IPA
./build_ios.sh ipa

# 导出 + Release Archive (App Store)
./build_ios.sh archive
```

### 5.4 产物清单

```
Client/build/dist/
├── MySpire-debug.apk          # Android Debug (测试安装)
├── MySpire-release.aab         # Android Release (Google Play)
├── MySpire.ipa                 # iOS (Development 或 App Store)
└── MySpire.xcarchive           # iOS Archive (Xcode Organizer)

Client/build/ios/
├── MySpire.xcodeproj           # iOS Xcode 工程
└── DerivedData/                # Xcode 编译缓存
```

## 7. 常见问题排查

### 7.1 Godot CLI 未找到

```
[ERROR] 未找到 Godot CLI。
```

**解决**：
```batch
REM 设置环境变量
set GODOT_PATH=C:\Godot\godot.exe

REM 或将 godot.exe 加入系统 PATH
```

### 7.2 Android 导出模板缺失

```
Export template not found: android_debug.apk
```

**解决**：Godot 编辑器 → 编辑器 → 管理导出模板 → 下载官方模板（4.3）

### 7.3 GodotGooglePlayBilling 插件未加载

```
Cannot find module: org/godotengine/godot/GodotGooglePlayBilling
```

**解决**：按照 `android/plugins/README.md` 下载插件文件放入 `android/plugins/`

### 7.4 Keystore 签名失败

```
Execution failed for task ':signReleaseBundle'.
```

**解决**：
1. 确认 keystore 文件路径正确
2. 确认密码与 `export_presets.cfg` 中一致
3. 确认 alias 为 `myspire`
4. 如果遗忘密码，需要重新生成 keystore（旧 AAB 无法用新 keystore 更新）

### 7.5 iOS Xcode 工程签名错误

```
Signing for "MySpire" requires a development team.
```

**解决**：
1. 打开 `build/ios/MySpire.xcodeproj`
2. 选择 MySpire target → Signing & Capabilities
3. 勾选 Automatically manage signing
4. 选择你的 Developer Team

### 7.6 InAppStore 信号未收到

```
[PaymentManager] iOS InAppStore 单例不可用
```

**解决**：
1. 确认导出预设 `capabilities/in_app_purchases = true`
2. 确认 info.plist 中包含 `SKPaymentPrivacy` 键
3. 确认 App Store Connect 中已创建 IAP 商品且状态为"可供出售"
4. 使用沙盒测试账号（设置 > App Store > 沙盒账户）

### 7.7 构建速度优化

- **Android Debug** 通常 30-60 秒（首次更慢，Gradle 需下载依赖）
- **Android Release** 增加 ProGuard 优化，通常 1-3 分钟
- **iOS Archive** 通常 2-5 分钟（取决于 Xcode 缓存）
- 如果 Gradle 构建太慢，配置 `gradle.properties` 镜像源
