# 杀戮尖塔（Slay the Spire）核心循环与经济系统分析

> **文档类型**: Mechanic Biopsy 参考文档
> **分析对象**: Slay the Spire (MegaCrit Games, 2019)
> **品类**: Roguelike Deckbuilder
> **用途**: 为新游戏概念验证提供设计参考
> **版本**: v1.0 | 2026-08-05

---

## 1. Fun Hypothesis

> **杀戮尖塔好玩的核心是：每张出牌同时是战术决策（活过这一回合）和战略投资（我的牌组在变成什么）。**

这不是两个独立的决策——它们发生在同一个动作里。你打出一张牌，既在解眼前的生存问题，又在塑造未来 50 局战斗的牌组走向。这种"即时决策"与"长期构建"的叠加，是 deckbuilder + roguelike 品类杂交的核心张力来源。

---

## 2. 核心循环（Core Loop）

### 2.1 Moment-to-Moment（0–30s）—— 回合内决策

| 阶段 | 玩家行为 | 设计意图 |
|------|---------|---------|
| 抽牌 | 从牌库抽 5 张到手牌 | 引入随机性——你永远不确定这回合能拿到什么 |
| 读意图 | 查看敌人下回合行动（攻击/防御/buff） | 将随机性转化为风险管理的已知变量 |
| 出牌 | 在 3 点能量预算内选择出哪些牌 | 核心决策——攻防权衡、能量分配、连锁触发 |
| 结算 | 卡牌效果执行 → 敌人行动 | 即时反馈——伤害数字、格挡动画、状态图标 |

**关键约束**: 基础能量 = 3/回合。这个数字经过精心调校——它恰好不够你同时"全力攻击 + 满格挡"，迫使每回合做出取舍。

### 2.2 Session Loop（5–30min）—— 楼层探索

| 阶段 | 玩家行为 | 设计意图 |
|------|---------|---------|
| 选路径 | 在分支地图上选择下一个节点 | 风险评估——精英守遗物、商店要绕路、篝火能回血 |
| 结算遭遇 | 执行战斗/事件/商店/休息 | 消耗 HP、金币、牌组资源 |
| 选奖励 | 拿牌？金币？遗物？或**跳过** | 最关键的经济决策——每张牌都是可选的负担 |

**关键设计**: 卡牌奖励永远可以跳过。这不是 bug，是核心机制——它让"不拿"成为一种合法策略选择，制造了牌组膨胀 vs 精简的持续张力。

### 2.3 Long-Term（hours–weeks）—— Meta 进阶

| 阶段 | 玩家行为 | 设计意图 |
|------|---------|---------|
| Run 结束 | 通关或死亡 | roguelike 的重置——HP/金币/牌组全部清零 |
| 解锁内容 | 新卡牌/遗物/角色加入随机池 | 丰富后续 run 的构建空间 |
| 飞升难度 | Ascension 1–20 逐渐加难 | 为老玩家提供持续挑战 |

**跨 run 经济控制**: 所有 run 内资源（HP、Gold、Cards、Relics）不跨 run 持久化，只有卡池/遗物池的解锁是永久的。这意味着没有跨 run 通胀——每次 run 都是一个独立经济模型。

## 3. Mechanic Biopsy —— 四个不可拆卸内核

剥掉 deckbuilder 和 roguelike 的类型外壳，杀戮尖塔真正起作用的机制内核有四个。拆掉任何一个，游戏循环都会塌方。

### 3.1 敌人意图明牌（Enemy Intent Telegraphing）

**机制**: 敌人每回合显示下回合行动（攻击 X 伤害 / 格挡 / 施加状态 / buff）。

**为什么是核心**: 这一个机制将卡牌游戏从"祈祷抽到好牌"转化为"已知约束下的优化求解"。玩家手里的牌是随机的，但敌人的行为是已知的——这种"半透明信息"创造了一个可计算的决策空间：给定敌人意图 + 我的手牌 + 我的能量，最优出牌序列是什么？

**验证**: 如果去掉意图明牌，玩家无法做战术规划，每回合变成纯赌博。核心循环的 moment-to-moment 层直接崩塌。

### 3.2 能量稀缺（Energy Scarcity）

**机制**: 基础 3 点能量/回合，卡牌消耗 0–3 点。

**为什么是核心**: 能量是回合级别的经济约束。没有它，玩家会出掉所有手牌——没有决策，没有取舍。3 点能量恰好不够"全力攻 + 满格挡"，这个数字是整个战术层的支点。

**验证**: 如果给 10 点能量，攻防权衡消失，每回合出所有牌即可，决策深度归零。

### 3.3 卡牌可跳过（Card Skip Option）

**机制**: 每次卡牌奖励可以选择"不拿任何牌"。

**为什么是核心**: 这让"积累"变成可选行为。在大多数游戏中，奖励 = 拿取，但杀戮尖塔允许玩家主动拒绝成长。这创造了牌组管理的核心张力——牌越多不等于越强，反而可能稀释关键牌的抽到概率。

**验证**: 如果强制每次必须拿牌，牌组会不可控膨胀，精简流打法消失，策略多样性减半。

### 3.4 路径分支 + 部分可见（Branching Paths + Partial Visibility）

**机制**: 地图是分支路径，玩家只能看到当前层和下一层的节点类型，更远的被迷雾遮挡。

**为什么是核心**: 这是让杀戮尖塔成为 roguelike 而非纯卡牌游戏的关键。路径选择引入了 meta 层面的风险管理——我要不要冒 HP 风险打精英拿遗物？要不要绕路去商店删牌？信息部分可见意味着你无法完美规划，只能基于局部信息做最优决策。

**验证**: 如果地图完全可见，玩家会算出最优路径，探索感消失。如果完全不可见（随机传送），规划感消失。部分可见是甜蜜点。

## 4. 经济系统（Sources & Sinks）

### 4.1 四大资源模型

| 资源 | Sources（来源） | Sinks（消耗） | 跨 run？ |
|------|----------------|--------------|---------|
| **HP** | 篝火休息（回 30%）、事件、遗物效果 | 战斗受伤、事件代价（血换力量） | 否 |
| **Gold** | 战斗奖励、事件、卖卡卖遗物 | 商店消费（买牌/遗物/药水/删牌）、事件 | 否 |
| **Cards（牌组）** | 战斗奖励（可选）、事件、商店购买 | 删牌服务（75g↑递增）、变形、牌组膨胀（隐性 sink） | 否 |
| **Relics** | 击杀 Boss/精英、商店、事件 | 无自然消耗（仅少量事件可牺牲） | 否 |

### 4.2 核心经济张力：牌组膨胀 vs 精简

这是杀戮尖塔经济系统最精妙的设计。卡牌既是资源又是负债：

- **拿牌的收益**: 新牌可能提供新能力、补强短板、开启连锁
- **拿牌的代价**: 牌组变厚 → 关键牌抽到概率下降 → 牌组身份稀释
- **跳过的收益**: 牌组保持精简 → 核心牌更稳定被抽到
- **跳过的代价**: 错过可能强大的卡牌

删牌服务定价 **75 金币起，每次递增**，这个定价本身就是设计声明——精简牌组被认为比堆叠更值钱。

### 4.3 隐性通胀风险

- **牌组膨胀**: 不是传统货币通胀，而是"抽到好牌概率"的贬值。自我限制系统——拿得越多，每张牌的边际价值越低。
- **遗物累积**: 遗物无自然 sink，力量在 run 内复合增长。平衡手段：遗物来源稀缺（精英/Boss 有限）、部分遗物双刃剑、Boss 遗物强制选择（3 选 1 或跳过）。
- **跨 run 零通胀**: 所有 run 内资源重置，只有卡池/遗物池解锁持久化。无跨 run 通胀风险。

## 5. Design Pillars

以下是我从游戏行为反推的五条不可妥协设计标准。每个设计决策都应通过这五条审验。

| # | Pillar | 含义 | 如果违反 |
|---|--------|------|---------|
| 1 | **每次 run 都不同** | 程序生成保证地图/奖励/事件/遗物组合的不可重复性 | 玩家发现"最优解"后停止探索 |
| 2 | **信息部分可见但公平** | 敌人意图明牌（公平），抽牌随机（不可控），地图部分可见 | 完全可见→无探索感；完全不可见→无规划感 |
| 3 | **构建身份涌现** | 玩家不在开局选 build，build 从卡牌/遗物选择中自然涌现 | 预设 build 限制了适应性决策的乐趣 |
| 4 | **每个奖励是真实选择** | 卡牌可跳过、Boss 遗物可跳过——拒绝是合法选项 | 强制接受会消除精简流，降低策略多样性 |
| 5 | **风险随回报缩放** | 精英守遗物、难路径给更好节点——高风险高回报 | 无风险分层 → 所有选择同质化 |

## 6. 可移植设计 DNA

以下五条设计原则不依赖 deckbuilder 或 roguelike 的类型外壳，可以跨品类移植。

| DNA | 核心原理 | 移植示例 |
|-----|---------|---------|
| **明牌机制** | 将敌人的部分行为提前展示，把纯随机转化为风险管理 | 动作游戏 BOSS 出招前摇；策略游戏对手意图提示 |
| **资源稀缺** | 在最小决策单元上施加严格预算，迫使取舍 | RTT 的行动点制；卡牌游戏的法力曲线 |
| **积累可选** | 允许玩家拒绝奖励，使"不拿"成为策略行为 | RPG 中装备槽位限制；生存游戏的负重系统 |
| **分支路径** | 提供多条可选路线，用风险分层创造 meta 层决策 | 肉鸽地牢的房间选择；竞速游戏的捷径设计 |
| **涌现式构建** | 玩家不预设 build，而是从碎片选择中自然形成身份 | ARPG 的装备驱动 build；自走棋的羁绊组合 |
