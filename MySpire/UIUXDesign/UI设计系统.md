# MySpire 竖屏 UI 设计系统

> 参考碧蓝幻想（Granblue Fantasy）视觉风格，为杀戮尖塔类 Roguelike Deckbuilder 适配竖屏移动端的 UI 设计规范。

---

## 1. 设计理念

### 1.1 视觉方向

| 维度 | 碧蓝幻想参考 | MySpire 适配 |
|------|------------|-------------|
| **色彩基调** | 深蓝 + 金色幻想风 | 保留深蓝底色 + 金色镶边，降低饱和度适配长时间游玩 |
| **UI 框架** | 华丽金边 + 半透明面板 | 简化金边为 1.5px 线条 + 角部装饰，保留质感不抢内容 |
| **信息密度** | 中高（PC/Web） | 降低（移动端可读性优先，单屏信息量减半） |
| **字体** | 衬线标题 + 无衬线正文 | Cinzel（英文标题）+ Noto Sans SC（中文正文） |
| **交互模式** | 点击 + 悬停 | 点击 + 长按（移动端无悬停，用 tap 预览替代 hover） |

### 1.2 竖屏适配核心原则

1. **纵向分区**：战斗画面从上到下分为 4 个功能带（顶栏 → 敌人 → 状态 → 手牌），每带职责单一
2. **横向滚动替代展开**：手牌区域使用横向 scroll-snap，卡片不重叠，可滑动浏览
3. **底部拇指区**：核心操作按钮（结束回合、确认）放在屏幕底部 1/3 区域，单手可触达
4. **垂直信息流**：地图、牌组、商店等列表型界面采用垂直滚动，符合移动端阅读习惯
5. **卡牌缩放**：手牌中卡牌缩小至 96×138px，点击放大预览；奖励/牌组场景使用 130×184px

## 6. 组件规范

### 6.1 卡牌 (Game Card)

**手牌尺寸**：96 × 138px
**奖励/牌组尺寸**：130 × 184px

```
┌─────────────┐
│ (1)    ┌────┤ ← 左上角：费用宝石（26×26px 圆形）
│        │    │
│  卡牌名称     │ ← 居中，11px/700，金色
│             │
│    [图标]    │ ← 卡牌图标区（52px 高，28px emoji）
│             │
│  效果描述     │ ← 居中，9px，带语义色高亮
│             │
│   类型标签    │ ← 底部居中，7px，灰色
└─────────────┘
```

**费用宝石**：26×26px 圆形，蓝色径向渐变 + 2px 蓝色边框 + 发光阴影
**边框**：2px solid，颜色由卡牌类型决定
**稀有度处理**：
- 普通：标准阴影
- 罕见：底部蓝色微光叠加
- 稀有：金色边框 + 底部金色微光叠加

### 6.2 按钮

| 类型 | 样式 | 尺寸 | 用途 |
|------|------|------|------|
| 金色按钮 | 金色渐变 + 金色边框 + 发光阴影 | padding: 12px 24px | 主要操作（启程、结束回合） |
| 深色按钮 | 深蓝渐变 + 金色细边框 | padding: 10px 20px | 次要操作（继续、图鉴） |
| 幽灵按钮 | 透明背景 + 灰色细边框 | padding: 8px 16px | 辅助操作（设置、排序） |

**交互**：hover 时亮度 +12% + translateY(-1px)；active 时 translateY(0)

### 6.3 HP 血条

- 高度：14px（敌人）/ 18px（玩家篝火界面）
- 背景：`rgba(0,0,0,0.6)` + 1px 金色半透明边框

- 样式：蓝色径向渐变 + 2px 蓝色边框 + 蓝色发光阴影 + 内部白色高光
- 文字：16px/700，白色

### 6.5 格挡护盾

- 样式：inline-flex，青色半透明背景 + 1px 青色边框
- 内容：🛡 图标 + 数值
- 字号：11px/700，青色

### 6.6 敌人意图标签

| 类型 | 背景色 | 边框色 | 文字色 |
|------|--------|--------|--------|

```
├──────────────────────────┤
│ ░░░░ 全屏立绘背景 ░░░░░░ │ ← 每角色一层，选中交叉淡入(550ms)
│      ◆                   │    + Ken Burns 缓慢缩放(1.2s)
│        ◆                 │ ← 紧密贴合菱形链（56px 菱形，
│      ◆                   │    水平偏移 ±40px = 半对角线，
│        ◆                 │    垂直中心距 40px → 边缘相切，
│      ◆ 🔒                │    中央金色引导线贯穿）
│        ◆ 🎲              │ ← 随机角色：紫金呼吸光晕，
│                          │    点击触发轮盘滚动后定格

│ 详情面板 (~120px)         │ ← 名称/称号/4格属性/遗物
│ （毛玻璃 + 内容入场动画） │    面板内容随选中刷新(400ms 上滑淡入)
├──────────────────────────┤
│ 底栏 (60px)               │ ← 启程按钮
└──────────────────────────┘
```

**菱形链几何**：菱形对角线 = 56 × √2 ≈ 79px；相邻菱形水平偏移 40px、垂直中心距 40px（`margin-top: -16px`），恰好顶点相切，形成连续不断的之字形链条。选中态 `scale(1.18)` + `z-index` 提升避免被相邻菱形遮挡。

**随机选项（🎲）**：紫色系渐变 + 2.2s 呼吸光晕区分于普通角色；点击后进入 `rolling` 状态（紫金交替闪烁），轮盘以 130ms/步 在可选角色间快速轮转（背景与详情面板同步切换），12–16 步后减速定格在随机结果。轮盘期间忽略重复点击。

**菱形导航规范**：
- 菱形尺寸 56×56px，rotate(45deg)，内图标反向旋转保持正立
- 排列：奇数项右偏 / 偶数项左偏，形成竖向交错链
- 状态：默认（金 40% 边框）→ 悬停（scale 1.1 + 金色发光）→ 选中（scale 1.22 + 双层金色光晕 + 内发光）
- 锁定角色：grayscale 降亮度，点击触发抖动动画（350ms），不可选中

**立绘背景层规范**：
- 结构：角色主题色径向渐变底 + 右侧大幅立绘 + 左侧竖排角色名水印（7% 白）
- 切换：`opacity 550ms` 交叉淡入 + `scale 1.08→1` Ken Burns 缓动
- 底部渐变遮罩（42%→84% 高度区间渐深）保证详情面板对比度 ≥4.5:1

**角色主题色**：铁卫 `#96221e` 系 / 静默猎手 `#1c5c34` 系 / 闪电法师 `#2a54be` 系 / 观心者 `#763ea8` 系

## 9. 交互模式

### 9.1 手牌交互

1. **浏览**：左右滑动横向滚动卡片（scroll-snap 对齐）
2. **预览**：点击卡片 → 卡片上浮放大 + 发光
3. **打出**：预览状态下再次点击 → 执行卡牌效果 → 卡牌飞向目标 → 消失
4. **不可打出**：费用不足时，费用宝石变灰，卡片不可点击

### 9.2 地图交互

1. **查看路径**：垂直滚动浏览地图
2. **选择节点**：点击可达节点 → 高亮选中路径
3. **不可回退**：已访问节点半透明，不可再次选择
4. **当前位置**：脉冲发光动画标识

### 9.3 卡牌奖励交互

1. **预览**：点击卡片 → 放大预览效果
2. **选择**：再次点击 → 卡牌飞入牌组 → 切换到地图画面
3. **跳过**：点击"跳过"按钮 → 直接切换到地图画面

|---------|---------------|------|
| `.device-screen` | `SubViewport` (390×844) | 竖屏渲染目标 |
| `.top-bar` | `HBoxContainer` + `StyleBoxFlat` | 顶部状态栏容器 |
| `.game-card` | `TextureRect` / `NinePatchRect` | 卡牌使用九宫格缩放边框 |
| `.hp-bar` | `TextureProgressBar` | HP 进度条 |
| `.energy-gem` | `TextureRect` + `Label` | 能量宝石（预渲染贴图） |
| `.panel` | `Panel` + `StyleBoxFlat` | 半透明面板（Godot 原生支持毛玻璃效果） |
| `.btn-gold` | `Button` + `StyleBoxFlat` (hover/pressed/focus) | 三态按钮 |
| `.hand-scroll` | `HScrollBar` + `HBoxContainer` 或自定义 | 手牌横向滚动 |
| `.map-scroll` | `VScrollBar` + `VBoxContainer` | 地图垂直滚动 |
| Screen 切换 | `SceneTree.change_scene_to_packed()` | 场景切换 |
| 卡牌悬停 | `Control.gui_input` + `Tween` | 缩放动画 |

## 13. 设计检查清单

- [ ] 所有画面适配 390×844px 竖屏尺寸
- [ ] 所有核心操作按钮位于底部拇指区
- [ ] 卡牌文字在 96×138px 尺寸下可读
- [ ] HP/能量/格挡数值在顶栏和状态栏双重显示
- [ ] 敌人意图使用颜色 + 图标 + 数值三重编码
- [ ] 卡牌类型使用边框色区分（红=攻击，绿=技能，紫=能力）
- [ ] 稀有度使用边框色 + 底部微光双重区分
- [ ] 地图节点使用颜色 + 图标双重区分
- [ ] 所有面板使用半透明 + 毛玻璃效果
- [ ] 金色边框用于强调核心元素（按钮、面板边框、标题）
- [ ] 画面切换使用 300ms 淡入过渡
- [ ] 卡牌悬停使用 200ms 上浮 + 放大 + 发光
